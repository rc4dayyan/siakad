# Panduan Pengguna SIAKAD per Peran

Dokumen pada direktori ini adalah panduan operasional terpisah untuk setiap jenis pengguna SIAKAD. Pilih panduan sesuai akun yang digunakan. Nama menu mengikuti aplikasi; menu dapat berbeda jika akun tidak aktif, periode belum dipublikasikan, atau kewenangan akun dibatasi.

## Daftar panduan

| Pengguna | Panduan | Fokus utama |
|---|---|---|
| Pengunjung tanpa akun | [Pengunjung Publik](PENGUNJUNG_PUBLIK.md) | Informasi publik, album, dokumen, dan saran |
| Web Administrator | [Web Administrator](WEB_ADMINISTRATOR.md) | Pengguna, konfigurasi akademik, periode, sistem, dan pengawasan lintas bagian |
| Departement Admin | [Departement Admin](DEPARTEMENT_ADMIN.md) | Administrasi umum dan publikasi |
| Departement Academic | [Departement Academic](DEPARTEMENT_ACADEMIC.md) | Mahasiswa, KRS, kurikulum, penawaran, jadwal, presensi, dan nilai |
| Departement Finance | [Departement Finance](DEPARTEMENT_FINANCE.md) | Tagihan, pembayaran, kas, administrasi KRS, dan approval |
| Departement Officer | [Departement Officer](DEPARTEMENT_OFFICER.md) | Dashboard, publikasi, dokumen, dan pelayanan informasi |
| Departement Support | [Departement Support](DEPARTEMENT_SUPPORT.md) | Gedung, ruangan, publikasi, dan bantuan operasional |
| Dosen | [Dosen](DOSEN.md) | Persetujuan KRS, jadwal, presensi, feedback, tugas, dan penilaian |
| Mahasiswa | [Mahasiswa](MAHASISWA.md) | KRS, jadwal, presensi, tugas, nilai, tagihan, dan ticket support |

## Ketentuan umum

- Ganti `[alamat-aplikasi]` dengan alamat resmi SIAKAD institusi.
- Staf masuk melalui `[alamat-aplikasi]/admin/auth-signin`; dosen melalui `/dosen/auth-signin`; mahasiswa melalui `/mahasiswa/auth-signin`.
- Gunakan **Ingat saya** hanya pada perangkat pribadi dan selalu **Logout** setelah selesai.
- Staf wajib memeriksa periode akademik pada header sebelum mengubah data.
- Jangan mengirim kata sandi, PIN, kunci pembayaran, atau cadangan basis data melalui ticket maupun kotak saran.
- Jika menu tidak muncul, periksa status akun dan peran, lalu hubungi Web Administrator.

Panduan gabungan tetap tersedia di [Panduan Penggunaan Aplikasi SIAKAD](../PANDUAN_PENGGUNAAN_APLIKASI_SIAKAD.md). Untuk prosedur khusus pembukaan periode, lihat [Panduan Persiapan Pembukaan Periode Baru](../panduan_persiapan_pembukaan_periode_baru.md).
